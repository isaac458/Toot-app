# Toot App v4.2 🚀

تطبيق "توت" الذكي - الآن أسرع وأقوى من أي وقت مضى!

## ما الجديد في v4.2؟
- **التحول الكامل إلى Groq AI:** وداعاً لمشاكل الصلاحيات والبطء في Gemini.
- **محرك Llama 3.3 70B:** استمتع بردود ذكية وصاروخية في أجزاء من الثانية.
- **إصلاح أخطاء الاتصال:** تم حل مشاكل 401 و 404 بشكل جذري عبر تغيير نظام التوثيق.
- **تأمين المفاتيح:** نظام جديد لإدارة المفاتيح عبر `local.properties` لمنع تسريبها.

## طريقة التشغيل:
1. احصل على مفتاح API من [Groq Console](https://console.groq.com/).
2. افتح ملف `local.properties` في المشروع.
3. أضف السطر التالي:
   `AI_API_KEY=your_groq_key_here`
4. قم بعمل Sync و Run!
